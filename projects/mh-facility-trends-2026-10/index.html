Trends in the Services Offered by US Mental Health Treatment Facilities, 2015–2024

N-SUMHSS
behavioral health
data tool
An interactive look at the share of U.S. mental health treatment facilities offering suicide prevention, eating disorder programs, telehealth, peer support, and 50-plus other services and payment options, from N-MHSS and N-SUMHSS.
Author

Joy Dada

Published

October 21, 2026

Every year, SAMHSA asks every known mental health treatment facility in the U.S. which services it offers and which payments it accepts. The answers are public, but over the years the survey changed its name, its file format, and some of its variable names. I combined ten years of files, 2015 through 2024, into one series. The charts below let you see which services became more or less common without cleaning the survey files yourself. Use the Years toggle above the charts to view all years together, only the N-MHSS years (2015–2020), or only the N-SUMHSS years (2021–2024).

Code 
trends = FileAttachment("trends.csv").csv({ typed: true })

optionsFor = chart => Array.from(
  d3.group(trends.filter(d => d.chart === chart), d => d.variable),
  ([variable, rows]) => ({ variable, label: rows[0].label, group: rows[0].group })
).sort((a, b) => d3.ascending(a.group, b.group) || d3.ascending(a.label, b.label))

// Y axis fits the data: at least a 20-point window, padded and snapped to
// the gridline step, clamped to 0-100%. Lines do not need a zero baseline the way
// bars do, and the fixed minimum window keeps small changes from looking huge.
yAxis = (series) => {
  const lo = d3.min(series, d => d.share), hi = d3.max(series, d => d.share);
  const span = Math.max(hi - lo, 0.2), mid = (lo + hi) / 2, pad = span * 0.15;
  let a = mid - span / 2 - pad, b = mid + span / 2 + pad;
  if (a < 0) { b -= a; a = 0; }
  if (b > 1) { a -= b - 1; b = 1; }
  // Gridline step grows with the range so there are about 4-6 lines:
  // 5 points for narrow ranges, up to 25 points for wide ones.
  const step = [0.05, 0.1, 0.2, 0.25].find(k => (b - a) / k <= 6) ?? 0.25;
  const domain = [Math.max(0, Math.floor(a / step) * step), Math.min(1, Math.ceil(b / step) * step)];
  return { domain, ticks: d3.range(domain[0], domain[1] + 1e-9, step) };
}

trendPlot = (series) => Plot.plot({

  width: Math.min(width, 860),
  height: 420,

  marginTop: 28,
  style: { fontSize: "16px", fontFamily: "Figtree, system-ui, sans-serif", background: "transparent" },
  x: { label: null, tickFormat: d3.format("d"), ticks: series.map(d => d.year) },
  y: { label: null, ...yAxis(series), tickFormat: d3.format(".0%"), grid: true },
  marks: [
    Plot.lineY(series, { x: "year", y: "share", stroke: "#B51D5A", strokeWidth: 3 }),
    Plot.dot(series, { x: "year", y: "share", fill: "#B51D5A", r: 5 }),
    Plot.text(series.slice(0, 1),
      { x: "year", y: "share", text: d => d3.format(".0%")(d.share), dy: series[1].share > series[0].share ? 22 : -16, dx: 8, textAnchor: "start", fill: "#B51D5A", fontWeight: 600, fontSize: 17 }),
    Plot.text(series.slice(-1),
      { x: "year", y: "share", text: d => d3.format(".0%")(d.share), dy: series.at(-2).share > series.at(-1).share ? 22 : -16, textAnchor: "end", fill: "#B51D5A", fontWeight: 600, fontSize: 17 }),
    Plot.tip(series, Plot.pointerX({ x: "year", y: "share",
      title: d => `${d.year}\n${d3.format(".1%")(d.share)} of ${d3.format(",")(d.n_facilities)} facilities that answered` }))

Intended use

This is a tool for people who want to explore how the availability of mental health services has changed over time. I haven’t drawn conclusions from it here, so please draw your own. You can use it as a starting point for research questions about where and how mental health services are offered. Each chart carries its own title and source line, so you can screenshot it and use it as is.

Data and methods

Download the data

  • trends.csv: one row per item and year, with the item name, group, share of facilities offering it, and the number of facilities that answered.
  • sample.csv: the number of facilities in the sample each year.

Please cite this page if you use the data. The code, codebook and data are on GitHub at jdada360/mh-facility-trends and archived on Zenodo: doi:10.5281/zenodo.23574161.

Sources

The 2015 to 2020 data come from the National Mental Health Services Survey (N-MHSS). In 2021, SAMHSA merged N-MHSS with the National Survey of Substance Abuse Treatment Services (N-SSATS) into one survey, the National Substance Use and Mental Health Services Survey (N-SUMHSS). I use the public-use files for every year, all from SAMHSA:

  • N-MHSS: 2015, 2016, 2017, 2018, 2019, 2020
  • N-SUMHSS: 2021, 2022, 2023, 2024

The series starts in 2015 because of a change in question format. The 2014 survey asked about each service as its own yes-or-no question. From 2015 on, the survey lists the services and asks facilities to mark all that apply. The two formats give quite different answers for the same item: 66% of facilities reported suicide prevention services in 2014, against 48% in 2015 and 54% in 2016. I left 2014 out so that every year in the charts uses the same format.

Which facilities count

For 2015 to 2020, I include every facility in the N-MHSS file. For 2021 to 2024, I include the facilities that completed the mental health section of N-SUMHSS, since these items are blank for facilities that only treat substance use. That is the closest match to the old N-MHSS group, though the two groups differ somewhat. Keep this switch in mind when comparing 2020 with 2021. In 2024 the mental health section grew to about 14,300 facilities, up from about 10,100 in 2023, so the 2024 point reflects a larger group with more outpatient providers.

The table shows how many facilities are in the sample each year. The total counts facility-years: most facilities answer in several years, so it is not a count of distinct facilities.

sample = FileAttachment("sample.csv").csv({ typed: true })

Missing answers

Each share counts only the facilities that answered that question in that year. The numerator is facilities answering “yes” and the denominator is facilities answering “yes” or “no.” If a facility skipped a question, left it blank, or has a missing code (−1 or −2), I drop it from that item’s share for that year. It still counts toward every other item it answered, so denominators differ across items and years. Hover over any point to see how many facilities answered.

Matching items across years

I kept only items asked in all ten years with the same yes/no coding: 54 in total. Most kept the same variable name throughout. I left out items first asked after 2015, such as transcranial magnetic stimulation, ketamine, and EMDR, because they don’t have a full series. The substance use side of the survey isn’t covered here either.

Caveats

Service offerings are self-reported by facility staff. Response rates differ by year (see each year’s codebook).

Use of AI

I built this page with Claude Opus 5.5, an AI model made by Anthropic. Claude matched variables across the survey years, wrote the code that cleans the data and draws the charts, and drafted the text. I chose the questions, checked the results against the survey files, and edited the writing.
